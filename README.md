# التوأم الرقمي لشبكة المياه — water-network-twin

لوحة تشغيل بأسلوب **SCADA** وتوأم رقمي لشبكة توزيع مياه، في ملف **HTML واحد قائم بذاته** (واجهة عربية RTL، سمتان فاتحة/داكنة). تعرض سلسلة المياه من التحلية حتى التوزيع، وتكشف الفاقد، وتربط أمن التشغيل (OT) بأثره التشغيلي.

> جميع البيانات **محاكاة داخل المتصفح** لأغراض العرض والتدريب — لا يوجد خادم خلفي.

## المكوّنات

- **مخطط شبكة حي 2D:** خزان رئيسي، محطة ضخ، و٤ مناطق قياس (DMA) مع تدفق متحرك.
- **مناطق القياس (DMA):** موازنة كتلية لكل منطقة وحساب المياه غير المُحاسَب عليها (**NRW %**).
- **حساسات ضغط/تدفق:** قيم حية على الخريطة ومخططات اتجاه (sparklines).
- **كشف التسرب:** اختلال الموازنة الكتلية + انخفاض الضغط، مع إنذارات على الخريطة وسجل مصنّف.
- **طبقة أمن OT:** جرد أصول (SCADA/PLC/RTU)، مراقبة Modbus/DNP3، وربط بمصيدة honey‑bit → Wazuh.
- **عرض توأم رقمي 3D (Three.js):** التحلية → الضخ → الخزانات → التوزيع، مع حالة كل أصل.
- **محرّك سيناريوهات الضخ والطاقة:** عدد المضخات العاملة → توزيع الأحمال → القدرة (kW) والطاقة النوعية (kWh/m³) ومنسوب الخزانات، مع مُحسِّن للتوزيع الأمثل.

## التشغيل

المشروع ملف واحد بلا اعتمادات بناء. افتح `water-network-twin.html` مباشرةً في المتصفح، أو قدّمه محلياً:

```bash
python3 -m http.server 8080
# ثم افتح: http://localhost:8080/water-network-twin.html
```

يتطلب العرض 3D اتصالاً بالإنترنت لتحميل مكتبة Three.js من CDN.
